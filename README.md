Una colección completa y modular de **37 componentes de interfaz de usuario (UI)** creados con tecnologías web puras (**HTML5, CSS3 y Vanilla JavaScript**), ideales para prototipar rápidamente proyectos web, plantillas PHP, sistemas de autenticación y paneles administrativos.

---

## 🌟 Características Principales

- ⚡ **Zero-Dependencies (Vanilla Web):** No requiere Node.js, React, Vue ni procesos de compilación complejos (`npm run build`). Copia y pega directamente.
- 🎨 **Diseño Moderno & Micro-animaciones:** Transiciones fluidas, diseño responsive, sombras elevadas y soporte para temas oscuros/claros.
- 📂 **Estructura Modular & En Español:** Cada componente tiene su carpeta autocontenida con `index.html`, `styles.css` y `main.js`.
- 🖥️ **Showcase Interactivo:** Incluye un dashboard principal (`index.html` en la raíz) con buscador, filtros por categoría y visor responsive para previsualizar en pantalla completa, tablet y móvil.

## 🖥️ Cómo Ejecutar el Catálogo Interactivo

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/ByChokeYT/componentes-html-css-js.git
   cd componentes-html-css-js
   ```

2. **Abre el Showcase:**
   Abre directamente el archivo `index.html` en la raíz de tu navegador favorito o utiliza una extensión de servidor local como **Live Server** en VSCode.

3. **Despliegue en GitHub Pages (Opcional):**
   - Ve a **Settings > Pages** en tu repositorio de GitHub.
   - En **Branch**, selecciona `main` y guarda.
   - Tu catálogo estará disponible públicamente en `https://bychokeyt.github.io/componentes-html-css-js/`.

## 🛠️ Tecnologías Utilizadas

- **HTML5 Nativo:** Estructura semántica accesible.
- **CSS3:** Variables CSS, Flexbox, CSS Grid y micro-animaciones.
- **Vanilla JavaScript (ES6+):** Manipulación limpia del DOM sin dependencias.
- **GSAP (GreenSock):** Librería para animaciones complejas de alto rendimiento.
- **Google Fonts & Iconos:** Plus Jakarta Sans, Outfit, Poppins y Boxicons.
