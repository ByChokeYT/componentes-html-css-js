---

## 🌟 Características Destacadas

- 🚀 **100% Vanilla Web (Zero Dependencies):** No requiere Node.js, React, Vue ni procesos pesados de compilación (`npm run build`). Funciona directamente en cualquier navegador o mediante `file:///`.
- 📦 **110 Componentes UI Organizados:** 39 componentes interactivos con Vanilla JS y 71 componentes modulares en Pure CSS3.
- 🎨 **Diseño Minimalista & Ergonómico:** Paleta oscura neutral (*Dark Zinc / Slate* estilo Linear y Vercel), proporciones compactas y sin saturaciones visuales artificiales.
- 📥 **Descarga en ZIP en 1 Clic:** Empaqueta y descarga al instante cualquier componente con sus archivos HTML, CSS, JS e imágenes locales listos para usar (gracias a *JSZip* y *FileSaver.js*).
- 💻 **Visor de Código con Prism.js:** Resaltado de sintaxis en tiempo real para HTML5, CSS3 y JavaScript con conteo de líneas, tamaño de archivos y botón de copiado rápido.
- 📱 **Modo Responsivo Multi-Dispositivo:** Prueba cada componente al vuelo en **Escritorio (100%)**, **Tablet (768px)** y **Móvil (375px)**.
- ⭐ **Motor de Favoritos Persistente:** Guarda tus componentes preferidos en `localStorage` con acceso rápido desde la cabecera.
- 🔍 **Búsqueda Inteligente & Ordenación:** Filtrado instantáneo por texto, etiquetas y tecnología (*Todos*, *Con JS*, *Pure CSS*, *Favoritos*), con selector de vista (Cuadrícula o Lista Compacta).
- 🤖 **Optimización SEO Integral:** Metadatos enriquecidos, Open Graph, Twitter Cards, Schema.org JSON-LD, [`sitemap.xml`](./sitemap.xml), [`robots.txt`](./robots.txt) y [`favicon.svg`](./favicon.svg).

## 🚀 Cómo Usar el Proyecto

### 1. Visualización Directa
Simplemente abre el archivo [`index.html`](./index.html) en tu navegador web (doble clic) o con una extensión como **Live Server** en VS Code.

### 2. Auto-Indexación y Sincronización
Si añades nuevos componentes o modificas carpetas, ejecuta:
```bash
npm run build
# o también:
node scripts/build-index.js
```
El script generará y actualizará automáticamente:
- `assets/js/components-data.js`: Catálogo de metadatos, tags y configuración de categorías.
- `assets/js/code-data.js`: Bundle de código fuente HTML/CSS/JS para visualización offline sin problemas de CORS.
- `sitemap.xml`: Mapa de sitio SEO con las 111 URLs actualizadas.
- `robots.txt`: Directivas de rastreo para buscadores.

## 🛠️ Stack Tecnológico

- **HTML5:** Marcado semántico, accesible y estructurado.
- **CSS3:** Variables CSS (Custom Properties), Flexbox, CSS Grid, Glassmorphism y micro-interacciones.
- **Vanilla JavaScript (ES6+):** Lógica modular sin librerías externas pesadas.
- **GSAP:** Animaciones fluidas para componentes especializados.
- **Prism.js:** Resaltado de sintaxis en el visor de código.
- **JSZip & FileSaver:** Empaquetado y descarga de componentes en formato ZIP.
